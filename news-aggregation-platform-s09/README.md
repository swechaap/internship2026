# NewsSphere AI

NewsSphere AI is a modern, fully interactive static web simulation for an AI-powered news aggregation platform.

## Features

- Landing page with live-style trending carousel
- Personalized dashboard with dynamic news cards
- Search, category filtering, sorting, and saved article counters
- News reader with source details, reading time, sentiment, keywords, and AI actions
- AI summary generator, fake news detector, sentiment analysis, keyword extraction, and Explain Like I'm 15 mode
- Floating chatbot for article questions, related recommendations, and simple explanations
- Analytics dashboard with Chart.js visualizations
- Admin panel for adding sources and reviewing reports
- Dark and light mode
- Responsive glassmorphism UI

## Run Locally

Open `index.html` in a browser, or serve the folder with any static web server.

## File Structure

- `index.html` - page markup and app layout
- `styles.css` - custom glassmorphism styling, animations, responsive refinements
- `script.js` - dummy news data, filtering, AI simulation, chatbot, counters, admin actions, and charts

## Deploy With GitHub Pages

1. Push this repository to GitHub.
2. Open the repository on GitHub.
3. Go to **Settings > Pages**.
4. Set **Source** to **Deploy from a branch**.
5. Choose the `main` branch and `/root`.
6. Save. GitHub will publish the site after the Pages build completes.
