 Overview
LibraFlow is an AI-powered Library Management System designed to simplify and modernize library operations for students, librarians, and administrators.
The system combines a responsive React frontend, a Node.js backend, and Google Gemini AI to deliver intelligent features such as semantic book search, AI-powered assistance, content summarization, predictive analytics, and smart recommendations.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
