# 🧪 Metal vs Non-Metal Challenge

## 📖 Project Overview

Metal vs Non-Metal Challenge is an interactive educational web application designed for students of Classes 7–9. The project helps students learn the differences between metals and non-metals through visual learning, interactive activities, quizzes, and gamified challenges.

The application aims to make science learning engaging, enjoyable, and easy to understand instead of relying on memorization.

---

# 🎯 Problem Statement (HMW)

**How might we help Class 7–9 students understand metals and non-metals through interactive learning instead of rote memorization?**

---

# 👤 User Persona

### Student Profile

* Name: Rahul
* Age: 13 Years
* Class: 8th Standard
* Goal: Learn science concepts easily
* Challenge: Difficulty remembering properties of metals and non-metals
* Preference: Visual learning, games, and interactive activities

---

# 📋 Requirements

## Functional Requirements

The application should allow students to:

* Learn about metals and non-metals
* View properties of metals and non-metals
* Classify materials correctly
* Play educational games
* Earn badges and achievements
* View leaderboard rankings
* Generate completion certificates

## Non-Functional Requirements

The application should be:

* Easy to use
* Mobile responsive
* Fast and lightweight
* Visually engaging
* Accessible for students
* Color-blind friendly

## Learning Requirements

After using the application, students should be able to:

* Identify metals and non-metals
* Explain their properties
* Classify real-life objects
* Compare metals and non-metals confidently

# 📚 Modules Implemented

## 1. Let's Learn Module

Interactive learning section containing:

* What are Metals?
* What are Non-Metals?
* Properties of Metals
* Properties of Non-Metals
* Comparison Section
* Real-Life Examples
* Knowledge Check Quizzes

---

## 2. Game Module

### Level 1 – Basic Classification

Classify:

* Metals
* Non-Metals

### Level 2 – Property Matching

Match properties with correct category.

### Level 3 – Real-Life Objects

Classify everyday objects into metals and non-metals.

---

## 3. Achievements Module

Students can unlock:

* Metal Master
* Non-Metal Ninja
* Science Champion
* Speedster
* Perfect Score
* Science Explorer

---

## 4. Leaderboard Module

Features:

* Top 10 Scores
* Player Ranking
* Local Storage Persistence

---

## 5. Certificate Module

Generates a personalized certificate containing:

* Student Name
* Score
* Accuracy
* Completion Date
